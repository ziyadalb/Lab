# ريض 111 — الكويز الثاني (4.2، 5.1، 5.2)

مواد مذاكرة عربية لطالب واحد لكويز الثلاثاء 27 أكتوبر 2026، مبنية من مذكرة د. طارق الفضل (2024) واختبارات المقرر السابقة 1445–1447.

**الحالة:** المذكرة الكاملة والاختباران التجريبيان جاهزة. السجل المرحلي والقرارات في `progress.md`.

## البناء من جديد
المتطلبات:
- Python 3.13 مع `sympy==1.14.0` و `pymupdf` و `pdfplumber`.
- Node مع `npm install` (KaTeX 0.16.22 والخط).
- Playwright 1.56 مع Chromium مثبت عامًا.
- poppler (`pdftotext`, `pdftoppm`).

```bash
# 1) من نسخك من الأصول (لا تُرفع إلى المستودع لحقوق النشر):
python3 tools/ingest_pdfs.py <مجلد الأصول> <مجلد الإخراج>   # نصوص وصور كل الصفحات للمراجعة
python3 tools/build_items.py                     # data/items.json من التعابير المراجعة يدويًا
python3 tools/verify.py                          # كل الأجوبة والحلول الرسمية والقوانين والاختصارات
python3 tools/select_holdout.py                  # الحجز (ثابت بالبذرة؛ لا يُعاد بعد التأليف)
# 2) الملفات: بناء، ثم KaTeX، ثم PDF، ثم الفحوص
./tools/build_guide.sh                           # المذكرة (تمريرتان لأرقام الصفحات) + فحص الجودة + فحص التسرب
./tools/build_mocks.sh                           # الاختباران
./tools/build_sample.sh                          # العينة
# 3) السجل وبيان التغطية (بعد البناء)
python3 tools/build_registry.py <transcribed_source.json>
python3 tools/coverage.py                        # COVERAGE.md
```

- كل صيغة تُطبع من التعبير نفسه الذي يُفحص، وأي فشل يوقف البناء.
- في جداول الاختصار، يُفحص القانون العام بمعاملات رمزية، ويُفحص كل صف أرقام بمساواة دقيقة، ويُفحص صف التعويض أنه جواب صحيح للمثال.
- الأسئلة المحجوزة ونسخها القريبة يرفضها `use()` في `tools/booklet_engine.py`.
