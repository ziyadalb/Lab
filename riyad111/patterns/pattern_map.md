## قواعد قرار مشتركة (مسودة، تُثبت عند فتح الأنماط)
**ق1 (تكاملات Q3):** ابدأ بشكل الدالة قبل اسم الطريقة:
- كسر من كثيرتي حدود ← خطوات P08: الدرجة، ثم المشتقة، ثم التحليل.
- جذر أو قوة 3/2 لـ `a^2 − x^2` أو `x^2 + a^2` أو `x^2 − a^2` بلا حد x ← P07.
- `1/sqrt(...)`، أو `1/((x−h) sqrt(...))`، مع حد x ← إكمال المربع ثم صيغة 4.2 (P05).
- ضرب نوعين مختلفين، أو دالة عكسية وحدها ← P06.
- أسس كسرية للمتغير x ← P09.
- قوى sin و cos أو tan و sec ← P10.

لا تُستعمل في المذكرة حتى تُفحص على الأسئلة الحقيقية لكل نمط.
