## قواعد قرار مشتركة (مسودة، تُثبت عند فتح الأنماط)
- **ق1 (تكاملات س2):** ابدأ بشكل الدالة قبل اسم الطريقة:
  - كسر من كثيرتي حدود ← خطوات P08 (الدرجة، ثم المشتقة، ثم التحليل).
  - جذر لتربيعية فيها x² وثابت فقط ← P07. وإذا كان فيها حد x ← إكمال المربع (P05 أو P07).
  - ضرب نوعين مختلفين (كثيرة حدود في مثلثية أو أسية أو ln أو دالة عكسية) ← P06.
  - أسس كسرية للمتغير x ← P09.
  - قوى sin و cos أو tan و sec ← P10.
  - دالة داخلية ومشتقتها موجودة ← P11.
- لا تُستعمل في المذكرة النهائية حتى تُفحص على الأسئلة الحقيقية لكل نمط.
