## 1. السؤال الحقيقي

المصدر: النهائي، الفصل الأول 1445، الجزء الثاني، السؤال 4 [3 درجات]. المعرّف `1445-S1-FE-Q2.4`، الملف `M 111 - (451-452) - English.pdf`، ص12.

```
Evaluate the following integral:

      ⌠  4x^2 - x + 12
      ⎮  ------------- dx
      ⌡     x^3 + 4x
```

- **المطلوب:** التكامل غير المحدد، والجواب ينتهي بـ `+ c`.
- **الرموز:**
  - البسط `4x^2 - x + 12` كثيرة حدود درجتها 2.
  - المقام `x^3 + 4x` كثيرة حدود درجتها 3.

## 2. كيف تعرف النمط من شكل السؤال

### الفكرة: هذا جمع كسور بالعكس
اجمع هذين الكسرين بتوحيد المقام:

```
 3      x - 1      3(x^2 + 4) + (x - 1)x      3x^2 + 12 + x^2 - x      4x^2 - x + 12
--- + ------- = ------------------------- = --------------------- = -------------
 x    x^2 + 4         x(x^2 + 4)                x(x^2 + 4)            x^3 + 4x
```

- المقام الموحد هو حاصل ضرب المقامين، لأن x و x²+4 ليس بينهما عامل مشترك.
- كل بسط يُضرب في المقام الذي ينقصه.
- الامتحان يعطيك الطرف الأيمن ويطلب تكامله. والطرف الأيمن صعب التكامل.
- لكن لو رجعت إلى الطرف الأيسر، فكل كسر فيه سهل: الأول ln، والثاني ln و tan^-1.
- **الكسور الجزئية = الرجوع من الكسر الواحد إلى الكسور البسيطة التي جُمعت.**

### الفحوص بالترتيب (قبل أن تعرف الحل)

| الفحص | في سؤالنا | إذا كان الجواب «لا» أو «نعم» تختلف الطريقة |
|---|---|---|
| 1. كسر بسطه ومقامه كثيرتا حدود؟ | نعم | لا ← نمط آخر، أو تعويض يحوله إلى كسر |
| 2. درجة البسط < درجة المقام؟ | 2 < 3، نعم | لا ← قسمة مطولة أولًا |
| 3. البسط = عدد × مشتقة المقام؟ | المشتقة `3x^2 + 4`، والبسط ليس من مضاعفاتها | نعم ← ln مباشرة، وهي الأقصر |
| 4. المقام يتحلل إلى عاملين أو أكثر؟ | `x^3 + 4x = x(x^2 + 4)`، نعم | لا ← فصل البسط أو إكمال المربع |

**القرار:** كسور جزئية. **البداية:** تحليل المقام.

### شكل التفكيك: قاعدتان تكفيان للبداية
- **عامل خطي** مثل `x` أو `x - 2`: يقابله `A/(العامل)`، والبسط ثابت.
- **عامل تربيعي لا يتحلل** مثل `x^2 + 4`: يقابله `(Bx + C)/(العامل)`، والبسط خطي.
- كيف تعرف أن التربيعية لا تتحلل؟ احسب b² − 4ac. لـ `x^2 + 4`: a = 1، b = 0، c = 4:

```
b^2 - 4ac = 0 - 16 = -16 < 0      →  لا تتحلل
```

- لماذا البسط فوق التربيعية `Bx + C` وليس ثابتًا وحده؟ لأن الكسر البسيط فوق مقام من الدرجة الثانية يمكن أن يكون بسطه من الدرجة الأولى. لو كتبت ثابتًا وحده فقد تفقد الحد `Bx`، فلا تجد ثوابت تحقق التطابق.
- (العامل المكرر مثل x² له قاعدة ثالثة تأتي في فرعه.)

## 3. الأساسيات المستعملة
- توحيد المقامات: انظر الجمع أعلاه.
- أخذ عامل مشترك: `x^3 + 4x = x(x^2 + 4)`، لأن x يقسم الحدين.
- فك الأقواس: `A(x^2 + 4) = Ax^2 + 4A`. لا تنسَ ضرب A في 4.
- ثلاثة تكاملات:

```
∫ dx/x = ln|x| + c
∫ x/(x^2 + a^2) dx = (1/2) ln(x^2 + a^2) + c        (u = x^2 + a^2 ,  du = 2x dx)
∫ dx/(x^2 + a^2) = (1/a) tan^-1(x/a) + c            (a > 0)
```

## 4. المثال كاملًا بالطريقة المعتادة

**الخطة:** حلل ← اكتب الشكل ← تطابق ← قارن ← كامل ← افحص.

```
x^3 + 4x = x(x^2 + 4)
```
عامل مشترك x. والتربيعية x²+4 لا تتحلل (b² − 4ac = −16).

```
4x^2 - x + 12        A       Bx + C
-------------  =  ---  +  -------
 x(x^2 + 4)          x       x^2 + 4
```
عامل خطي ← A. تربيعية ← Bx + C.

```
4x^2 - x + 12 = A(x^2 + 4) + (Bx + C)x
```
ضربنا الطرفين في x(x²+4): كل كسر يفقد مقامه ويُضرب في العامل الذي ينقصه، مثل الجمع في الجزء 2.

```
4x^2 - x + 12 = Ax^2 + 4A + Bx^2 + Cx
              = (A + B)x^2 + Cx + 4A
```
فككنا القوسين، ثم جمعنا الحدود حسب قوة x.

```
x^2 :   A + B = 4
x   :   C = -1
1   :   4A = 12   →   A = 3
        3 + B = 4  →   B = 1
```
كثيرتا حدود متساويتان لكل x ⇔ معاملاتهما متساوية قوة بقوة.

```
4x^2 - x + 12      3       x - 1
-------------  =  ---  +  -------
   x^3 + 4x        x      x^2 + 4
```

**فحص قبل التكامل** (عوّض x = −1 في الطرفين):

```
يسار:  (4 + 1 + 12)/(-1 - 4) = 17/(-5) = -17/5
يمين:  3/(-1) + (-1 - 1)/(1 + 4) = -3 - 2/5 = -17/5      ✓
```

**التكامل:** نفصل البسط x − 1 إلى x و −1:

```
∫ = 3 ∫ dx/x  +  ∫ x/(x^2 + 4) dx  -  ∫ dx/(x^2 + 2^2)

  = 3 ln|x| + (1/2) ln(x^2 + 4) - (1/2) tan^-1(x/2) + c
```

- ln|x| بالقيمة المطلقة.
- `ln(x^2 + 4)` بلا قيمة مطلقة، لأن x² + 4 > 0 دائمًا.
- معامل tan^-1 هو 1/a = 1/2.

## 5. اختصاران مثبتان على المثال نفسه

**(أ) الإخفاء (cover-up) لثابت العامل الخطي:**
- غطِّ العامل x في المقام، وعوّض جذره x = 0 في الباقي:

```
A = (0 - 0 + 12)/(0 + 4) = 12/4 = 3
```

- **لماذا يصح:** في التطابق `4x^2 - x + 12 = A(x^2+4) + (Bx+C)x` ضع x = 0. الحد الثاني يختفي لأنه مضروب في x، فيبقى `12 = 4A`. وهو نفس التعويض الذي يستعمله الدكتور في المذكرة («Put x = 2»، ص83)، لكن بلا كتابة التطابق.
- **الشرط:** العامل خطي وغير مكرر، والكسر درجة بسطه أقل.
- **ما لا يفعله:** لا يعطي B و C للتربيعية.

**(ب) القراءة المباشرة (فقط للمقام `x(x^2 + a^2)` بالضبط):**
- إذا كان البسط `p x^2 + q x + r`، فإن:

```
A = r / a^2         C = q          B = p - A
```

- هنا p = 4، q = −1، r = 12، a² = 4:

```
A = 12/4 = 3        C = -1         B = 4 - 3 = 1
```

- **لماذا:** في `A(x^2 + a^2) + (Bx + C)x`:
  - الحد الثابت يأتي من `a^2 A` فقط.
  - حد x يأتي من `Cx` فقط.
  - حد x² هو `A + B`.
- **الشرط:** العامل الخطي هو x نفسه، والتربيعية بلا حد x. في `(x+1)(x^2+x+1)` (نهائي 1447 الأول) **لا تصلح**، وقد ثبت ذلك بالفحص.

**الترشيح (مبدئي):**
- الطريقة الأساسية: المعتادة، مع (أ) لإيجاد A أولًا، لأنها تصلح لكل فروع الأسئلة السابقة.
- البديل: (ب) للسرعة أو للتأكد عند المقام `x(x^2+a^2)` فقط.
- يتغير الترشيح حسب محاولاتك.
