# riyad111 — مذاكرة ريض 111، الاختبار الثاني (الميد تيرم 2)، 17 نوفمبر 2026

| الملف | ما هو |
|---|---|
| `progress.md` | الحالة الحالية، والسؤال المنتظر، والإجراء التالي. **ابدأ منه** |
| `scope.md` | النطاق المحتمل ودليله، وفهرس الملفات والصفحات |
| `patterns/pattern_map.md` | الأنماط الثمانية داخل النطاق، وتكرارها، والأولوية، وخطة الأيام |
| `chapters/P08_draft.md` | فصل الكسور الجزئية (مسودة، الأجزاء 1–5). **هذا للقراءة** |
| `patterns/P08_partial_fractions.md` | بطاقة النمط الكاملة وسجل الاكتشاف (فيها أجوبة: بعد المحاولة) |
| `data/questions.csv` | سجل الأسئلة بمعرّفات ثابتة ونمط كل سؤال |
| `research/research_log.md` | البحث الخارجي وروابطه |
| `tools/`، `reports/` | سكربتات التحقق (SymPy) ونتائجها. **فيها أجوبة، لا تفتحها قبل المحاولة** |
| `data/holdout.json` | الأسئلة المحجوزة لاختبار الاستقلال. **للمعلم فقط** |

إعادة التحقق:

```bash
pip install sympy==1.14.0
python3 -I riyad111/tools/verify_p08.py      # من جذر المستودع
python3 -I riyad111/tools/build_registry.py  # يعيد بناء data/questions.csv من سجل math111-quiz2
```
